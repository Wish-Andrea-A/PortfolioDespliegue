## Permisos.gitignore Razón
#### Está pensado para evitar archivos con información sensible
Información sensible como podrían ser las contraseñas, configuraciones propias del dispositivo que lo hagan identificable, evitar archivos maliciosos etc.
## Qué hacer para que tengamos una convivencia segura
* Creen copias de seguridad
* Usen ramas protegidas
* Soliciten y revisen las pull request
### Se puede garantizar que nuestros proyectos no se pierdan teniendo un sistema robusto de copias de seguridad, esto incluye copias en el servidor, en pc locales o discos duros
